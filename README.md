#Project - PoserOS

##系统信息
- 作者: Poser(破晓)
- BITS: 32位
- 启动: BIOS
- 架构: 8086 (x86)

- 最低硬盘: 1MB
- 最低内存: 64MB

声明：本人是一名学生，没有很多时间去修改该OS，并且本人C语言水平较差，内核中可能会出现很多漏洞。

##系统设计

###Bootloader
Bootloader在实模式读写以下信息:
```
0x8000   4 字节   E820 条目数
0x8004   4 字节   内存容量（字节）
0x8008   4 字节   硬盘容量（扇区）
0x800C   24*N     E820 条目

0x90000          栈顶
0x10000          内核入口
0xB8000          VGA
```
