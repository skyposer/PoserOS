#Project - PoserOS

##系统信息
- 作者: Poser(破晓)
- BITS: 32位
- 启动: BIOS
- 架构: 8086 (x86)

- 最低硬盘: 1MB
- 最低内存: 64MB

声明：本人是一名学生，没有很多时间去修改该OS，并且本人C语言水平较差，内核中可能会出现很多漏洞。

##使用说明
如果需要真机启动，直接使用系统镜像。
如果需要QEmu启动，将build.sh中的DISK填写为自己的qcow2硬盘镜像。
