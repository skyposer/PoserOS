PoserOS

Powered by VM!

一部用 C 语言与汇编从零搭起来的 32 位 x86 操作系统 —— 自写启动引导、内存管理、分页、进程与系统调用， 搭载一套由 shellVM + dawnVM + limasm 组成的 VM 驱动链，让系统的大部分功能由虚拟机承载，而非一条条活在内核里的 C 函数。

Layered Design

从裸机到用户态的分层架构

整个系统是一条清晰的分层栈：BIOS 引导进入内核，内核把硬件抽象成系统调用，上层再跑 shell 与工具 —— 而关键的任务则交给内置于用户态的 VM 引擎执行。

应用 · 用户态 ring3 · 由 VM 驱动
内建程序以自研 PEXC 格式运行在 0x04000000 起的独立虚拟地址空间，各自拥有独立 CR3 页表。

Under the Hood

内核都扛了什么

这套内核并不“能用就行” —— 它有真实的物理内存管理器、分页、进程模型、根 / 用户双身份权限，以及 26 个经过设计的系统调用。

Memory

物理内存 + 分页

读 int 0x15 / E820 得到内存映射，PMM 按物理页分配；每个进程一张自己的 CR3 页表，用户态与内核态在虚拟地址空间上隔离。

Process

进程模型

proc_create → proc_load → proc_boot 三步拉起用户程序，从内核态引导进入 ring3，支持 exec / wait / exit 进程生命周期。

Security

双身份权限

/system 目录对普通用户只读，写 / 删 / 重命名一律返回 PFS_EPERM；root 与 user 身份可切换，提权程序需在 PEXC 头标记并校验身份。

Abstraction

系统调用接口

全部经 int 0x80 + eax/ebx/ecx/edx 约定，C 侧由 pstd_kapi.h 封装成 sys_* 包装函数，覆盖 IO、文件系统、进程、时间与控制台。

Command Line

命令行与系统调用特点

壳层 PoserShell 直接映射底层能力：统一调用约定、自研可执行镜像、双身份权限，以及内核内置的一套开发工具。

The Core Concept

Powered by VM

整个系统
由虚拟机驱动

“虚拟机驱动”不是口号，而是 PoserOS 真实的分层引擎：三套 VM 组件从上到下撑着整个运行链 —— 交互壳、字节码执行、汇编产出， 共同把系统的关键功能搬离内核 C 代码，放进虚拟机的世界里。

shellVM提供 PoserShell 框架 —— 命令解析、内置编辑器、su / sudo 提权的交互壳层，由虚拟化框架承载。
dawnVM字节码解释 + 安装包底层 —— DawnByteCode (.dwn) 解释执行，并负责安装包的装载与运行底座。
limasm内置汇编器 —— 把自研汇编源码编译成可被 VM 执行的镜像，是 VM 世界的手工生产线。

从 limasm 产出字节码，由 dawnVM 解释、打包、安装、运行， 再交给 shellVM 的 PoserShell 呈现成命令与交互 —— 一条完整的 VM 驱动链。

我们正在逐步把系统的一部分功能转为虚拟机架构托管 —— 这是 PoserOS 一直走的路。

引导信息

实模式引导器把 E820 条目数、内存容量、硬盘扇区数写到 0x8000 处，交给保护模式内核。

用户态隔离

每个用户程序有独立 CR3 页表，最多 1MB 的 .exc 镜像，从 ring3 运行。

持久磁盘

构建时以 qcow2 镜像承载 FAT 卷，内核首次启动把安装负载落盘为真实文件系统。
